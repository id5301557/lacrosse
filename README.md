# Aldermere & Harrowgate 대학 홈페이지

## 바로 열기

`index.html`을 브라우저에서 여세요. 설치나 빌드가 필요 없습니다.

상단 **EN / 한국어**로 언어를 바꿀 수 있습니다. 한국어 본문은 제공된 한국어 고정설정을 직접 정리하고, 영어 본문은 별도로 현지화했습니다. 영어 화면을 한국어로 재치환하지 않습니다. 페이지·학교 이동뿐 아니라 선수 탭, 로스터 검색, 행사 필터, 열람 승인 상태도 언어 전환 시 유지됩니다. 한국어 선수 이름으로도 검색할 수 있습니다. 이미지에 포함된 글자는 원본을 유지합니다.

한국어 제목은 프로젝트에 포함한 **Noto Serif KR**을 사용합니다. SIL Open Font License도 함께 포함했습니다. 본문·메뉴·카드·내부 표는 Pretendard / Apple SD Gothic Neo / Noto Sans KR / 맑은 고딕 / system-ui 순서의 고딕체를 사용하며, 설치된 글꼴에 따라 표시됩니다. 일반 본문은 16px, 내부 본문은 14px 이상입니다.

유니폼 사진 8장은 증명사진과 동일한 **13:19** 비율입니다. 원본 해상도에서 크롭했으며, 리사이즈 없이 무손실 WebP로 저장했습니다. 저장 후 원본 크롭과 픽셀 일치 여부를 검사했습니다.

- 메인 / Aldermere: `index.html` 또는 `aldermere/index.html`
- Harrowgate: `harrowgate/index.html`
- 상단 **University Directory**에서 학교를 바꿀 수 있습니다.
- 모든 공개 페이지 상단의 **Staff Portal**과 라크로스 로스터의 **Athletics Staff / Restricted Records**에서 선수 디렉터리를 엽니다.
- 선수 프로필의 **View Restricted Record → Continue as Athletics Staff**를 누르면 원래 선택했던 선수 기록으로 바로 이동합니다. 이미 교직원 세션에 들어갔다면 재인증하지 않습니다.
- **Restricted Record 한 페이지**에서 기본·선수 경력·가족·행동·관계·진로를 세로로 읽습니다. 상단 Anchor Navigation은 같은 페이지의 섹션으로 이동합니다. 출처는 작은 태그로 구분하며 내부 탭·별도 Private 페이지는 없습니다.
- 최고 민감정보만 **Sensitive Personal Data**로 접혀 있습니다. 버튼을 누르면 주의 Modal이 먼저 뜨고, 확인 후 같은 페이지 안에서 펼쳐집니다. 취소·Escape는 접힌 상태를 유지합니다.

## GitHub Pages 업로드

1. ZIP을 풀고, **이 README와 index.html이 있는 폴더의 내용 전체**를 GitHub 저장소 루트에 올리세요. ZIP 파일 자체를 올리는 방식이 아닙니다.
2. 저장소의 **Settings → Pages**를 여세요.
3. **Source: Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택하고 **Save**를 누르세요.
4. Pages에 표시되는 주소에서 사이트를 엽니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

모든 이미지·페이지 링크는 상대 경로라 `사용자.github.io/저장소이름/` 형태의 프로젝트 주소에서도 작동합니다. `.nojekyll`을 포함했습니다. 외부 글꼴을 불러올 수 없으면 기본 글꼴로 표시되며 핵심 기능에는 영향이 없습니다.

## 파일 구조

```
index.html
aldermere/     학교별 공개 페이지 + staff/index.html
harrowgate/    학교별 공개 페이지 + ravens-house.html + staff/index.html
shared/       공통 CSS / UI 동작
data/         대학 및 선수 8명의 고정 설정
assets/       학교·팀 로고, 선수 사진, 제한 문서, 캠퍼스 전경·지도
```

설립연도는 제공된 로고 기준 Aldermere 1883년, Harrowgate 1892년입니다. 재학생 수는 approximately로 표시합니다. 경기 결과, 의료 승인, 미제공 선수와 과거사는 임의로 추가하지 않았습니다.

공개 선수 페이지에는 공개 약력과 사진만 있습니다. 가족·생활 정보는 내부 기록, 깊은 내면정보는 출처 미확인 개인 메모로 구분했습니다. 학적 이미지와 이미지 열람 기능은 제거했습니다.

추가 정사 수정도 반영했습니다. 레오는 미·일 복수국적 출생 후 20세 전에 본인의 진로·생활기반을 고려해 미국 국적을 선택했으며, 아버지의 반대로 거리감이 생겼습니다. 그랜트의 할아버지는 대학 라크로스 선수였습니다. 정확한 법률 절차, 대학명, 활동 연도는 임의로 붙이지 않았습니다.

## 캠퍼스 이미지 교체

학교마다 `assets/<학교>-panorama.svg`와 `assets/<학교>-map.svg` 두 슬롯이 있습니다. 전경과 지도는 서로 독립적입니다. PNG/WebP 등으로 교체할 때는 `data/schools.js`의 해당 학교 `assets.hero.src` / `assets.map.src`만 바꾸세요. 지도는 1200:850 비율을 권장합니다. 시설의 `point: [가로%, 세로%]`는 건물 위치이며, 번호 버튼은 `markerPoint`를 따르고 없으면 `point`를 따릅니다. CSS의 지도가 이미지에 맞게 늘어나므로 다른 비율을 쓸 때는 `shared/revision.css`의 지도 비율도 조정하세요.

현재 지도는 시설 탐색용 자체 개념도입니다. 실제 지형·거리·시설 위치를 확정하는 측량 자료가 아닙니다. Aldermere는 Founders’ Green 중심의 열린 녹지, Harrowgate는 Old Quad 중심의 조밀한 벽돌·석조 캠퍼스와 강변으로 구성했습니다. 페이지 생성 작업은 교체된 이미지를 덮어쓰지 않습니다.

권한 경고는 탐색용 시뮬레이션입니다. 실제 보안·인증·접근 감사는 없으며, 정적 파일의 데이터와 첨부 이미지는 소스에서 확인할 수 있습니다. 이 폴더에는 실제 계정 비밀번호나 인증키가 포함되지 않습니다.


## 추가 설정 반영

새 메인 발췌와 키워드북에서 경기 강점·선수 경력·생일·가족·주거·생활·말투, 25개 시설의 용도, Dark와 공동생활, 대표 행사 상세를 보강했습니다. Harrowgate도 제공된 12개 시즌 경기 일정을 표시하며 상대교·결과는 임의로 만들지 않았습니다. Fountain Run은 비공식 학생 전통입니다. 최신 메인 기준 라키는 3형제 중 둘째이며 그랜트의 할아버지·아버지·삼촌 모두 대학 선수입니다. 이전 키워드북의 외형과 충돌하는 경우 최신 메인의 백금발·짧은 언더컷을 사용했습니다.

지도 시설의 `point`는 건물 위치, 선택적인 `markerPoint`는 번호 버튼 위치입니다. 번호를 건물 밖으로 옮겨도 건물 자체를 움직일 필요가 없습니다. Aldermere의 Hawthorne Hall과 종탑 번호를 분리해 종탑 시계가 가려지지 않게 했습니다.

상세 기록은 한 페이지의 1열 섹션으로 재편했습니다. SWEET 4인의 생활·가족·취미·음주·진로·관계 방식, Ravens의 일상 교류·원정·공동생활, 양교 대표 행사 15개의 작은 활동을 원문에 따라 표시합니다. Harrowgate 행사에는 원문 소이벤트 72개가 포함됩니다. 빈 정보에 대한 제작 안내는 표시하지 않으며 새 직업·사건·관계는 만들지 않았습니다.

선수 공개 프로필의 이름 옆에는 제공된 `signatures-simple-v3_13` 버전의 투명 PNG 사인을 표시합니다. 작은 화면에서는 이름 아래로 배치하며, `assets/<선수 ID>-signature.png`를 교체하면 해당 선수의 사인만 바뀝니다. 원본 해상도와 투명 배경을 유지했습니다. 주노의 가족 지원 차이 기록은 두 사실 문장을 유지하고 작성용 마지막 안내 문장만 한·영 모두 삭제했습니다. 대학 선택 창의 방문 버튼은 소개 문구의 줄 수에 관계없이 같은 높이로 정렬됩니다.
